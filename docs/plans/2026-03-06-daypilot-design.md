# DayPilot AI Personal Time Manager 设计文档

日期：2026-03-06
状态：已确认（待实施）

## 1. 产品愿景

DayPilot 是一个 AI 驱动的个人时间管理助手。用户通过自然语言输入任务和目标，AI 自动解析、判断优先级、估算时间并生成可执行日程，同步到用户日历。

### 目标用户
- 知识工作者/白领
- 自由职业者/创业者
- 多角色人群（工作 + 家庭 + 个人成长）

## 2. MVP 范围（第一阶段）

### 2.1 核心价值
优先打透：**自动生成日程**

### 2.2 MVP 必做功能
1. 文本自然语言输入任务（语音后续迭代）
2. AI 任务解析（自然语言 -> 结构化任务）
3. 最多 2 轮澄清追问（缺少关键字段时）
4. 自动优先级判断（四象限 + 截止时间）
5. 自动估时与自动排程
6. 日历同步（Google 优先，Apple 后续）
7. 未完成任务自动重排

### 2.3 MVP 不做
- 团队协作
- 复杂报表
- 大量第三方深度集成
- Gamification
- 语音输入（当前阶段）

## 3. 系统架构设计

### 3.1 技术选型（MVP）
- 前端：Next.js + TypeScript
- 后端：FastAPI + Pydantic
- 数据库：PostgreSQL（云端主存储）
- 缓存/队列：Redis + Celery
- AI：LLM 任务解析 + 规则排程引擎
- 日历同步：Calendar Adapter（Google 优先，兼容 CalDAV）

### 3.2 数据存储策略
采用：**云端 PostgreSQL + 本地缓存（IndexedDB）**

原因：
- 支持多端同步
- 支持后台自动重排
- 支持日历 token 安全托管
- 保证数据备份与恢复

### 3.3 核心模块
1. Chat UI：对话式任务输入
2. Task Parser：任务结构化解析
3. Scheduler：规则化自动排程
4. Calendar Sync：日历同步
5. Replanner：自动重排
6. User Store：用户偏好与历史数据

## 4. 多轮沟通策略（体验关键）

### 4.1 追问规则
- 默认最多 2 轮追问
- 每轮只问 1 个问题
- 只追问排程必须字段（deadline、duration）
- 超过 2 轮仍缺失则自动使用默认值继续排程

### 4.2 默认兜底
- duration 默认 60 分钟
- priority 默认普通（近截止自动升高）
- 可拆分默认是

### 4.3 体验目标
- 降低用户输入负担
- 避免无限追问导致疲劳
- 保证“先排出来，再优化”

## 5. 产品路线图

### 5.1 P0（上线必须）
1. 登录系统
2. 文本任务输入
3. 2 轮澄清机制
4. 自动排程
5. Google Calendar 同步
6. 今日/本周计划展示

### 5.2 P1（上线后）
1. Apple Calendar 同步
2. 自动重排增强
3. 拖拽调整
4. 偏好学习

### 5.3 P2（验证后）
1. 周期任务
2. 语音输入
3. PWA
4. 更多日历平台

## 6. 核心指标（MVP 验证）

- 任务解析成功率 >= 85%
- 平均追问轮次 <= 1.2
- 日历同步成功率 >= 95%
- 首次任务完成时间 <= 10 秒
- 7 日留存率（关键）

## 7. 风险与应对

1. 排程不合理 -> 提供排程理由 + 允许一键重排
2. 成本过高 -> 小模型优先，大模型按需升级
3. 日历 API 变更 -> 适配层抽象 + CalDAV 兜底
4. 用户隐私顾虑 -> 最小化采集 + 可导出可删除

## 8. 实施原则

- 先实现 MVP，再优化
- 先验证用户价值，再扩展功能
- 先保证可用性，再追求技术完美

---

当前确认结论：
1. 输入方式：文本优先（语音后续）
2. 数据方案：云端 PostgreSQL + 本地缓存
3. 后端技术：FastAPI + Pydantic（MVP）
4. 策略：先实现 MVP，后续优化
